# 工道好物

让好商品背后，也有好工作。一个面向中国企业及在华业务的开放商品资料目录，以 **每周标准工时不超过 40 小时、每周至少休息 2 天** 为筛选起点，继续追踪具体商品的制造和服务供应链。

[访问网站](https://hancao97.github.io/fair-labor-goods/) · [资料共建](CONTRIBUTING.md) · [研究记录](docs/research.md)

当前版本包含 30 件商品或产品系列、17 份企业档案、53 条来源，覆盖电子数码、家居、家电、日用快消、文化娱乐和电子游戏。按关联企业资料分为 6 件制度披露、11 件岗位线索、13 件待补证。**这不是已认证企业名单**：当前没有独立考勤验证或全供应链实际履约已核实的商品。

常用商品已包括手机、笔记本、平板、充电器、耳机、书桌照明、座椅、收纳、冰箱、洗衣机、洗碗机、扫拖机器人、牙膏、洗衣液、沐浴露、雪糕、杂志、积木、手柄和电子游戏。各类的证据强弱与市场限制见[覆盖情况](docs/research.md#常用商品覆盖情况)，不能将商品数量理解为达标数量。

## 功能

- 商品和底层企业名称检索、常用商品快捷查找、六类筛选、资料状态筛选、排序。
- 商品劳动档案：原始来源、发布日期、查阅日期、适用主体和例外。
- 研发、制造或外包、上游等环节分别记录，避免将总部政策扩大到整条供应链。
- 浏览器本地收藏；筛选和商品链接可分享。收藏不跨设备同步。
- 企业档案、来源资料库、JSON 下载、GitHub Issue 资料提交入口。
- 手机和桌面布局、键盘操作、原生对话框、减少动态效果设置，无 emoji。

## 本地运行

需要 Node.js 22.12 或更高版本。

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173/fair-labor-goods/`。

```sh
npm run check:data
npm test
npm run build
npm run preview
```

技术栈为 React、TypeScript、Vite，图标采用 Lucide SVG。无需服务端、数据库或 API 密钥；商品图片保存在项目内，页面不依赖 Google Fonts 或外部图片加载。

## 数据维护

主数据位于 `public/data/catalog.json`。每项产品对应企业档案与独立的商品关联来源；企业档案中的劳动来源不会被产品官网替代。图片来源与权利信息位于 `public/data/image-credits.json`。更新数据后同步修改 `updatedAt` 并运行检查。

资料整理日期表示人工查阅日期，不能替代内容发布日期，也不等于实际劳动条件的验证日期。旧来源、来源未知日期、不同法人和旺季例外应保留显著说明。

## GitHub Pages

`.github/workflows/pages.yml` 会在 `main` 推送后验证数据、运行单元测试、构建并发布；PR 只运行检查与构建。仓库的 Settings → Pages → Source 需设为 **GitHub Actions**。部署使用 `github-pages` 环境。

CI 自动使用仓库名称生成站点基础路径，并更新 GitHub 共建链接。仓库改名后修改本文链接与本地默认配置即可；自定义域名可通过 `PAGES_BASE_PATH=/` 构建。路由使用 hash，商品分享使用查询参数，适配 GitHub Pages 无服务端路由的环境。
