# 从员工工作体验出发研究公司

查阅日期：2026-09-13。

后续批次见[胖东来员工反馈与食品研究](pangdonglai-employee-research.md)，最新数量见[工厂体验与零售对应](factory-experience-and-retail.md)。下文保留首批发布时的记录。

按用户建议，调查顺序调整为：先看员工怎么说，筛出值得继续研究的公司，再核对该公司的劳动资料、自产商品或自营服务及大陆购买渠道。同一主体已有适用依据时可以对应多款商品，不重复调查公司。不要求每家公司先有政府A级，也不把零加班、固定双休加成法律门槛。

网站新增“员工怎么说”，同时显示资料形式、发布日、经历时期、岗位与地点范围。亲身陈述、采访、转载和内推宣传分别记录；身份未独立核实、时期不详或只取得公开索引的情况会写明。资料表单允许只推荐公司，暂未找到商品时无需先填购买链接。

通知正文经官方公开索引读取，原站直接请求和附件返回403；不再重复同一请求。只有取得新的原始资料、近期具名员工经历或明确的主体关系时，才继续这条核对路径。TapTap也以公开索引为渠道依据，普通HTTP虽返回200但实际为验证页面，未宣称下载到原始商品正文。三份运营政策、心动采访、宝洁脉脉转载和静安结果均取得普通HTTP正文。

## 变化与验证

新增1份公司线索档案、10条来源及3条结构化员工经历；补齐3款游戏的大陆使用与境内运营服务说明。共243条商品与服务、173份企业档案、701条来源；正式收录仍为35项、待核查208项，32项需求已有正式覆盖、163项未覆盖。没有把这次渠道补全写成新增合规商品。

同步清理帕斯亚、椰岛档案中残留的“40小时+双休待补证”，改为实际用工主体和适用劳动依据，数字游戏的供应链说明改为开发运营、美术测试及发行服务。

校验包括数据引用、反馈来源去重及必需范围字段；另验证员工正面经历不能替代缺失的劳动依据，并运行现有测试、构建和部署核对。
