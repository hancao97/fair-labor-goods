# 常熟加工企业与张家港鲜肉购买

复核日期：2026-09-13。

新增正式商品为张家港青草巷吴宗宝鲜肉经营部的牛后腿肉，水果生鲜类别首次覆盖牛肉需求。另新增学子膳黑椒柳条1kg/袋待核查资料：制造及劳动依据已对应，准确个人零售入口尚未找到。

全站269条商品和服务、193份企业档案、838条来源；55项正式收录、214项待核查。199项细分需求中50项有正式商品、149项待补。生鲜仍有12项缺口，不能把一款牛肉写成生鲜全覆盖。本轮未取得可核对的新增员工本人经历，员工资料仍为19家企业、28条记录。

## 消费者怎么买

[市场官网](http://www.zjgqcx.com/zjgqcxWeb/scgk/)给出现址：张家港市锦丰镇合兴兴南路8号，并设鲜肉交易区和客服中心。[2026-09-04政府网供销社访谈](https://www.zjg.gov.cn/zjg/lszb/202609/3c6113664c6f4abd8d154c233b60cdcf.shtml)回答消费者购买问题，明确可到青草巷市场购买散装农产品。

商品限定“张家港市锦丰青草巷吴宗宝鲜肉经营部”的牛后腿肉，链接提供市场地址与导购。食品表未列定量包装，没有补造500g、1kg、摊位编号或全国配送；重量、分切、价格与供货由摊位确认。收录依据为具名销售记录与当前到店渠道的结合，未核验本次库存。

## 相近商品没有混入

- 小邱摊位的五花肉在2025年记录中来自常熟食品，2026年记录中来自南通海门兴旺。已发现不同生产企业，不能将该摊位所有五花肉继续套用一家厂的劳动结果。本批未收录其猪肉。
- 吴宗宝摊位的羊肉、羊软肋排肉对应太仓金仓湖，不能沿用牛肉制造企业的评价。
- [白云区原始食品PDF](https://www.by.gov.cn/attachment/7/7638/7638882/9772986.pdf)第13页第139行将学子膳黑椒柳条1kg/袋对应江苏虞恒及常熟厂址，已下载并目视核对。虞恒在常熟最终名单“支塘镇（40家）”组。学校食堂采样没有当成个人零售入口，同品牌鸡米花、鸡排也没有替代本款。
- [虞恒项目报告](https://20899323.s21i.faiusr.com/61/ABUIABA9GAAgztvHiQYorKff9QQ.pdf)的监测时期为2020年；班制页列二班、每班8小时。它是项目运行披露，不能推算每位员工年工作4800小时，也不替代年度劳动依据。
