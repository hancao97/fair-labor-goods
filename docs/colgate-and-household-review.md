# 牙刷工厂员工线索与日用品复核

查阅日期：2026-09-13。

本批新增高露洁三笑有限公司的扬州牙刷工厂候选档案、1条员工经历和2条来源。全站175份企业档案、719条来源，其中6家公司有9条员工反馈。商品仍为247条，38项正式收录、209项待核查；36项细分需求已有正式商品或服务、160项未正式覆盖。没有将公司线索计作新增守法商品。

## 从岗位体验推进工厂调查

[职朋公司页面](https://www.job592.com/pay/comxc287174.html)中的供应链管培生条目，标注工作地点扬州、经历年份2022年、投稿日2022-11-02。投稿者称通常按时下班、周末偶有加班，并列有五项社会保险和住房公积金。它提供了具名公司与具体岗位线索，适合作为进一步研究牙刷工厂的起点。

这是一条匿名个人陈述，身份未独立核实。未公开具体车间、合同和加班报酬，不能代表全部生产操作工。本次取得公开索引正文，普通HTTP连接超时；未再重复请求。页面的2025年更新时间不是这段经历的发生时间，跨年份汇总和后面的招聘报价也没有成为工时、工资结论。同页的实习生经历没有拆成额外反馈条目。

[高露洁官方亚太招聘页](https://jobs.colgate.com/content/Location---Asia-Pacific/?locale=zh_CN)确认中国三笑牙刷生产基地，补充境内制造方向。该页面另列的羽毛球活动、家庭日分别涉及黄埔工厂和天河办公室，不能移到扬州。企业工厂介绍不等于劳动审核。

## 劳动结果已到哪一步

1. [省级拟认定名单附件](https://file.smejs.cn/group1/M00/05/31/rBIAAWV5YJ2AAr_cAAM2t69miXA596.pdf)第11页具名高露洁三笑有限公司；该文件标题明确写“拟认定”。
2. 复用此前保存的[最终名单附件副本](https://file.m12333.cn/upfile/download/ec66c49c-7378-3144-584e-1aa7fb5cc97a.pdf)，读取全文并渲染、目视核对第8页，也有同名公司及扬州三和四美酱菜有限公司。它与拟认定文件不同，资料库没有重复新增这条来源。
3. 副本没有完整发布正文和可直接确定的正式发布日期。本次尚未取得该企业最终结果的发布原件。膳魔师江苏的具名官方颁牌报道只核验膳魔师，不能借给名单中的其他公司。政府原页普通请求403、第三方索引页412后停止，未绕过访问限制。

保留以上正面线索，尚未新增可支持商品收录的劳动评价。没有将“没取得最终原件”写成企业违法，也没有要求另找A级、零加班或固定双休。

## 商品对应与重新检查条件

高露洁三笑有限公司、江苏三笑集团有限公司、高露洁棕榄（中国）有限公司分别研究。国内“三笑牙刷”零售搜索混有三笑美洁、三笑完美、可洁可净等不同品牌或主体，商品标题出现“三笑”不能直接归给高露洁三笑。

[深圳2021年牙刷抽查附件](https://www.sz.gov.cn/attachment/0/940/940292/9509964.pdf)第11行提供DARLIE牙刷的历史制造线索，但没有足以识别当前零售型号的完整信息，不能把今天所有好来牙刷都归给该工厂。本次只记录调查方向，没有新增不明确的商品。

接下来值得继续的资料是：可核对的具名最终劳动结果、新近具体生产岗位经历、牙刷包装制造商及相应零售型号。出现其中的新资料后继续对应，暂停对同一旧网页和相同泛词的重复请求。

## 其他日用品的停止条件

本批对已有缺口继续定向核对，未产生足以升级商品的新依据：

| 方向 | 本次结果与后续条件 |
| --- | --- |
| 上海乐美等文具 | 新取得的青浦2022年度通知仍不能替代2017年评价的原始标准。施耐德品牌介绍指向德国制造，不能用于补中国制造文具。取得对应年份的具名结果及适用标准，或具体中国工厂的新审核后再查。 |
| 金红叶与维达纸品 | 企业责任报告、自动化报道及旧招聘可提供背景，未取得新的适用综合劳动结果。南通2022年检查涉及建厂施工承包商工资，不能移给纸厂员工；不同厂区与办公室分别对应。 |
| 联合利华、宝洁 | 取得的正面体验主要涉及办公室；现有生产招聘没有补齐具名工厂的实际劳动信息。先找可对应生产岗位与地点的新材料。 |
| 开兰1kg面粉 | 仍是同一企业官网的地区展示页，尚缺个人零售入口；地区页面名称不等于新的工厂地址。 |
| 洁雅Babycare湿巾 | 仍缺与既有JY制造记录相符的当前零售包装；未猜测抽数，也没有把企业年报当成单款包装证据。 |
| 粤师傅调味油、名味春卷等既有食品 | 仍缺可读制造标签或存在口味对应冲突；没有新资料时不重复旧页面。 |

此次公司候选仍未填补牙刷、纸笔等正式商品缺口。后续优先使用新的具名工厂材料，同一适用公司劳动依据可以供其多款自产商品共用。

## 验证

数据校验、UTC时区下的45项测试和生产构建均通过。在本地生产预览中搜索“高露洁”并启用员工反馈筛选，结果保留该工厂；目视核对员工经历的2022年日期、供应链管培生岗位、匿名来源及待补资料均完整显示。
