# 中粮东海与两款食用油收录

复核日期：2026-09-13。

正式收录福临门非转基因一级大豆油5L和黄金产地玉米油5L，均限定中粮东海粮油工业（张家港）有限公司制造版本。两款从现有待核查资料转入正式目录，商品资料总数仍为269；正式收录57项、待核查212项，覆盖52/199项需求。粮油食品增至18项正式商品，覆盖16/36项需求，新增大豆油、玉米油两个缺口。

## 先复核公司，再对应产品

原福临门档案记录的是营销公司，虽然已经找到中粮东海的劳动结果，仍因“当前批次、逐周考勤和原料来源”等额外条件搁置。此次新建制造企业档案，两款共用该厂劳动依据；营销公司下的花生油、家香味菜籽油继续按各自实际厂家研究。

以“中粮东海、脉脉、加班、职朋、工资、双休”等组合检索后，未取得适用于该厂的可用一手员工经历。脉脉上的中粮集团招聘文章、仪表岗位介绍和其他企业的相似职位没有计作员工反馈。员工资料数量保持19家企业、28条记录；没有帖子不自动排除企业。

玉米油是组合资料作出的制造对应判断：系列名单未写容量，北京表未写“黄金产地”，不能描述为单份政府表直接列出完整商品名称。转载中的好粮油荣誉期限已于2026年8月届满，仅用于历史制造关系，不作现行质量荣誉或劳动认证。未把另一处同源转载当成第二份独立证据。

零售页没有独立保证每次发货厂家，因此名称与说明明确限定中粮东海制造版本，购买时可核对包装制造企业。当前地区库存和成交价未验证，也没有为了确认渠道而提交订单。成品在中国生产不推定全部原料来自中国，更不声称逐一确认了每名工人的国籍。
