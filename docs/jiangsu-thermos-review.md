# 江苏制造企业与厨具证据复核


后续已补齐昆山TCC独立劳动档案，所列两家制造企业分别有依据，TCLF-720S现已正式收录；详见[昆山员工经历与厨房商品](thermos-employee-products.md)。下文保留首次调查时的结果。
查阅日期：2026-09-13。

本次新增膳魔师江苏制造企业的政府综合劳动评价档案，以及TCLF-720S亚光黑720mL焖烧罐的一条待核查商品资料。全站237条商品与服务资料、165份企业或门店档案、656条来源；正式收录保持32项，待核查205项。没有把新增研究资料算作新增合规商品。

## 已确认的企业劳动评价

[淮安市人社局2024-04-16报道](https://rsj.huaian.gov.cn/col/3932_871247/art/17119008/1713436014312OatFyqzx.html)明确记载，4月12日向膳魔师（江苏）家庭制品有限公司等企业颁发“省级优秀劳动关系和谐企业”奖牌。使用已读取的政府原页公开索引；原页直接请求返回403后停止，没有绕过限制。

该结果可以采用政府综合劳动评价路径，不要求另找A级。[淮安评价程序说明](https://rsj.huaian.gov.cn/col/3932_871247/art/o/17067168/1707298860843htazvfON.html)载明企业自评、职工满意度测评和三方共评。本次又沿[国家标准平台](https://std.samr.gov.cn/db/search/stdDBDetailed?id=949D7DB5676E94DAE05397BE0A0A6D0D)的公开链接，取得DB32/T 2019—2019的11页原始PDF并核对正文与页面。

标准第4.1、4.3—4.6节包含劳动合同、工资及加班报酬、工作时间、休息休假、社会保险与劳动保护；第5.1节列否决事项，第7—8节规定三方评价与结果。它能说明评价涉及哪些劳动权益，不能证明企业每一项满分。

记录使用2024-04-16官方颁牌报道日期，实际审查起止日和单项评分未公开。较早结果不是2026年新检查，本站安排2026-10-13前再查也不等于官方有效期。未把未知日期变成额外拒绝条件。

另读到官方劳动争议开庭日程，其中有该企业的劳动报酬事项，但没有裁决。页面2024年发布、标题为2021年日程，不能据此认定企业2024年欠薪，也不能假定企业胜诉。商品留待核查的原因是下面的制造对应缺口，不是把开庭日程当作违法认定。

## 验证

数据校验、UTC环境下41项现有测试及TypeScript/Vite生产构建通过。本次只更新资料和研究记录，没有修改判定程序。逐项比对确认原32项正式收录及原236条商品资料全部保持不变；新增商品仅国内销售环节有支持资料，制造对应与适用劳动依据仍待核查。

大陆销售、境内制造、生产劳动三个环节分别有支持资料的数量为121、64、42，不能将独立环节数量相加或当作正式收录数量。厨房13项需求有研究记录，仍无正式收录商品。
