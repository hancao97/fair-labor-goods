# 苏州金记：豆干与豆奶

查阅日期：2026-09-13。新增苏州金记食品有限公司档案，正式收录老相食五香豆干145g×2袋、五谷豆奶250mL×30袋。同一制造企业的适用劳动资料用于两款产品，不重新要求逐款考勤或当前批次证明。

## 公司与劳动依据

先检索苏州金记、脉脉、加班、工资、岗位等资料，没有取得适用本厂的可用一手员工经历。公司组织的座谈会、招聘和企业新闻未记作独立员工证言，员工资料仍为19家企业、28条记录。

采用[苏州2021—2022年度最终结果](https://www.suzhou.gov.cn/szsrmzf/bmwj/202312/fb542a977d564a3b83c9fa56fa2fba69.shtml)：原始DOCX的**4A级、吴中区21家**部分，第4个为苏州金记食品有限公司。文件2023-12-22成文、2023-12-27公布。结合已读取的[劳动保障复查原表](https://www.suzhou.gov.cn/szsrmzf/bmwj/202205/0fe327e037424f1ba8b2e3d77638abff/files/f063d6e71bd74dd2bd1728cd881c8c95.xls)及[后续复查通知](https://www.suzhou.gov.cn/szsrmzf/bmwj/202404/8c5c94ed44df4624a9933f580f5e5c8d.shtml)，通过现有政府综合劳动评价路径判断，未修改准入规则。

[2023—2024年度公示](https://hrss.suzhou.gov.cn/jsszhrss/gsgg/202512/a0b593234ebe47dca84ad412f356ccab.shtml)也将该公司列为拟4A级，位置为4A级吴中区23家第4个，但公示不能冒充最终授予。未取得企业完整分项表或实际审查起止日；查阅日不更新评价年度，2026-10-13是本站计划复核日期。

[2024年度社会责任报告](https://www.jjfood.com.cn/nd.jsp?id=807)提供较近的生产地址、业务及劳动制度自述。[2022年保供报道](https://www.jjfood.com.cn/nd.jsp?fromMid=3&groupId=2&id=523)提到加班，但未披露时长和费用，不把公司写成零加班，也不直接据此作违法结论。劳动评价限苏州金记法人，不自动覆盖供应链子公司、豆腐文化公司和独立加盟商。

## 覆盖与下一步

新增豆干需求后，清单为200项需求，其中54项已有正式商品；总目录271条，正式59、待核查212，195家企业、853条来源。新增两款涉及两个需求，其中豆干是新补清单，原有缺项实际减少一项，不能把数量变化全部写成填平旧缺口。

内酯豆腐与薄百叶已有官网和部分制造线索，具体个人零售范围仍待整理；清单还需要继续补入这类常见食材。白雪冷柜已查型号与厂家，但当前零售和原始制造记录型号不同，停止原样重复搜索。美的清洁电器的旧评价和较近招聘工时线索存在需要解释的差异，招聘不等于已核实的实际劳动情况，未据旧名单直接收录。后续优先取得新资料，避免重复检索同一受限页面。

本批数据引用校验、49个既有测试和生产构建通过，并核对新增条目及覆盖统计。未改应用准入逻辑、既有商品状态或员工反馈数量。
