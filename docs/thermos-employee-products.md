# 昆山员工经历与两款厨房用品

查阅日期：2026-09-13。

新增正式商品为**膳魔师FEI-501WH白色保温杯500mL、TCLF-720S亚光黑焖烧罐720mL**。后者沿用已有商品ID。厨房首次覆盖水杯、饭盒两项需求；全站252条资料中43项正式收录、209项待核查，196项需求中41项已正式覆盖、155项尚未覆盖。

## 先从生产员工经历找到公司

[2023年苏州日报采访](https://jsnews.jschina.com.cn/zt2023/ztgk_2023/202311/t20231124_3323302.shtml)明确采访膳魔师（中国）家庭制品有限公司制造部组立班宝妈产线。受访者谈到为照顾孩子转岗、重新工作的收入和生活体验；报道另介绍6小时、8小时岗位及五险一金。两名受访者属于同一报道，合并为一条来源记录。

[2026年昆山市妇联刊载的报道](https://www.ks.gov.cn/kss/funv/202604/adc752b01f2d483882365dbeb7b3cdc8.shtml)中，一名从一线岗位成长的员工谈到下午五点下班接孩子。该文使用品牌简称，本次依陆家镇同名产线与2023年具名采访对应昆山企业；不是全厂重新审核。两文对项目启动年份表述不同，未据此确定启动日。

两条均标为媒体采访，保留岗位、地点、时间及局限。没有用特定产线安排推算全体员工周工时，也没有把昆山员工经历套给淮安员工。员工资料增至9家公司、14条记录。

## 多家可能制造企业的处理

新增可选字段`manufacturerOptions`，逐家记录企业档案、实际制造法人、工厂范围（如适用）、制造来源及劳动结果指针。只有所列企业全部符合范围和日期要求时才正式收录；任何一家缺少依据、到期、撤回或出现更新相反事实，本款都返回待核查。

这解决了原模型只能接受单一制造主体的问题：已明确列出的两家都具备适用依据时，无须硬等杯底代码来猜一个。若只能证明其中一家、厂家列表尚不明确，或者发现新的制造企业，仍需继续调查。页面分别展示各家的日期、范围、员工经历、局限与供应链资料；在任一家企业页都能找到关联商品。单一制造商的已有资料继续兼容，数据版本更新为5。

检查覆盖多家均有效、缺失企业或来源、主体及厂区不符、到期、撤回、后续相反结果、重复选项，以及额外供应链筛选不能只检查一家。运行数据检查、49项测试、TypeScript与生产构建，再核对桌面及手机页面和发布版本。

办公学习仍未新增正式商品。晨光平台汇总混有销售、物流、检测等不同岗位，不能把少量投票百分比当成全公司工时分布；后续有具体员工帖子或生产主体的新资料再继续。安硕信息技术的员工经历不用于安硕文教，品牌相近不是同一雇主。
