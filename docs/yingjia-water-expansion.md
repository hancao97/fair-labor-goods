# 迎驾山泉饮用水收录复核

查阅日期：2026-09-12。

正式收录迎驾山泉饮用天然水550mL×24瓶（野岭剐水），对应安徽迎驾山泉股份有限公司。本批完成后共175条商品与服务资料、114家企业、476条来源；24项正式收录、151项待核查。16个生活领域、189项需求中的137项已有资料，52项仍缺，调查覆盖数没有因同类商品增加而膨胀。

霍山名单和六安抽检PDF的直接请求返回403，因此本次依据其公开索引正文，不声称取得了这两份原始文件。抽检PDF截图也未成功取得。省级通知转载的原始HTML已保存并与市级通知核对；转载标示的安庆政府原文返回403，合肥转发附件返回521。来源条目均保留取得方式和局限。

购买依据为查阅日公开零售卡片；详情仅返回网站框架，没有据此宣称实时库存、价格或全国配送。新老包装随机，制造主体、容量或品名变更时应重新核对。小图保留来源与权利说明，不单凭图片判断产地、劳动条件或健康功效。

劳动评价只用于具名法人及相应审查范围，不扩展为迎驾集团、经销商和包材运输企业全部合规的结论。本站复核日期设为2026-11-03，与其他2025年公布的安徽评价采用相同维护方式；该日期不是政府设定的评级有效期。

同时复查了先前零收录的实现原因：额外的双休、含加班40小时、全部上游记录门槛及零数量断言已移除。本批沿用修正后的规则，既有174款商品的判定保持不变。数据检查、22项测试和生产构建通过后发布，并以线上文件与本地构建的字节比对核实更新。
