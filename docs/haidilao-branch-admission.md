# 宿州海底捞具名门店收录

查阅日期：2026-09-14。

海底捞6斤番茄锅·宿州华夏世贸店由待核查转为正式收录，首次补上火锅需求。全站288条商品与服务中，正式收录增至68项、待核查220项；204项细分需求中63项有正式商品、141项待覆盖。新增1条政府食品许可来源，总计952条；企业档案仍为208份，员工资料仍为27份档案、37条，没有将许可或菜单算作员工反馈。

此前只差该门店与已有劳动评价的经营企业之间的对应关系。本次取得的政府食品许可解决了这一点，随后重新核对原始劳动名单和当前同店菜单。

食品许可原页由埇桥区政府网站公开，发布日期2024-07-02。该分公司有2024-06-04核发、2024-06-13变更两条记录，信用代码为91341302MA2TLMQ15Y，许可证为JY23413021034460。两行经营地址一致，均包含大型餐饮及热食等制售范围。所列2029-06-03是食品许可届满日，与劳动评价期限无关。

本次结合具名许可、准确铺位、官方门店和同店餐品，判断所选番茄锅对应该分公司的境内制作与服务。收录范围为这家宿州门店；原料加工、中央供应和独立配送雇主的情况另行记录，店址不用于推断每位工人的国籍。劳动依据是2024年审查结果，没有写成2026年新检查或全国海底捞均符合要求。本站安排2026-12-15前复核，届时或出现更新相反线索、主体变化时再判断。

“6斤”保留为菜单名称，没有据此填写已核净重、锅格或就餐人数。所用页面提供具体到店消费线索，份量、价格与当日供应以本店菜单为准。门店营业时长没有当成员工实际工时；2025年集团ESG披露继续作为补充资料。

同份劳动名单里的宿州肯德基门店继续保留为研究线索。本轮未取得足够的准确门店消费对应，没有借用其他城市或大润发店的菜单。已有待核查记录及其各自缺口保持原状。

数据校验、52项现有测试及TypeScript/Vite生产构建均通过。逐项比较确认原67项正式商品全部保留，仅本款番茄锅转入正式目录；其他287条商品及207份企业档案保持不变。当前商品数和需求覆盖数均由实际准入判定计算。
