# 员工线索与游戏收录

查阅日期：2026-09-13。沿用“先看员工经历，再核公司资料，批量对应商品”的顺序，本轮将已有的三款心动国服游戏服务转为正式收录，并增加一条联想办公室经历。

## 心动：一次公司核对，适用三款服务

起点是已记录的[2021年员工采访](https://finance.sina.cn/tech/2021-06-21/detail-ikqcfnca2244979.d.html?from=wap&fromtech=1)。采访有拒绝无必要周末加班的经历，也有项目冲刺期加班；仍按一篇报道计，不推定所有团队零加班。

此前已取得[静安区2022年度正式结果](https://www.jingan.gov.cn/rmtzx/003001/20230825/420683eb-edea-4e16-893d-11f7e6494b53.html)，2023-08-25公布并具名心动网络股份有限公司。本轮通过长宁区公开的[2022年创建通知及完整指标表](https://zwgk.shcn.gov.cn/xxgk/xzqr-rsjzhzw/2022/267/33012/a65e4ad2727a481c85e3528f16c42226.pdf)补齐标准：第1—3页明确依据同一沪人社关〔2022〕107号，采用市级终审及授予称号；第10—14页涵盖六类劳动权益及否决情形。长宁文件用来核对同批标准，心动获评事实来自静安名单。

综合评价可以作为具名用人单位的支持依据，不要求企业取得所有福利指标满分。数据保留2022年度和实际公布日；未取得分项得分、完整审查起止日或后续逐年复审结果。[集团2025年报](https://img.xdcdn.net/xdwp/2026/04/20260429130340311.pdf)的标准工时、特殊工时和加班审批用于补充制度，不能改写为2026年新政府评价。本站计划2026-10-13前复核，这不是政府授予的有效期。

## 联想和电脑工厂

[2024-11-20牛客自述](https://www.nowcoder.com/discuss/688704298062024704)描述联想办公室弹性工作和休假，已加入员工反馈。作者身份、城市和劳动合同法人未独立核实；正文由公开索引取得，普通HTTP仅返回页面框架。帖子未指向联宝工厂，不能用于认定所列电脑制造工人的待遇。

联宝定向查询仍只取得企业介绍、招聘及缺原始年份的A级徽标。戴尔线索主要涉及办公室、技术支持及实习预期，未对应制造工厂；没有新增一款缺少实质资料的电脑来凑数。后续以新的工厂员工经历、机型制造标签或具名劳动结果为重查条件。

[天逸510S具体货号页面](https://item.lenovo.com.cn/product/1052505.html)能核对型号与配置，但普通HTTP同时带有购买、预售及下架模板，浏览器加载超时。保留销售状态待确认，明确缺口不在实时价格或库存证明，未从隐藏模板推断在售或停售。

另排除一篇[汇川工作体验帖](https://www.nowcoder.com/discuss/657555299250798592?sourceSSR=enterprise)：原作者在评论中明确承认由AI写作，不能当成亲历。本轮也未把平台“一键发评”的建议文字当作实际员工评论。
