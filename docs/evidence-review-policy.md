# 劳动证据与研究方法修正

首次修正日期：2026-09-12；2026-09-13补充未公开完整审查期的正式综合结果表示方式。

此前代码只接受政府劳动保障守法A级，页面也把所有正式收录统一写成A级。这是项目自行设置的单一证据入口，并不等于劳动法要求企业取得该评级。它限制了其他可靠资料的使用。现已增加政府综合劳动评价和独立劳动审核入口，同步修改判定、数据校验、商品标签、详情、筛选及收录标准页。

首次修正保留了既有商品的证据结论，没有因修改规则而自动升级企业自述、招聘或旧荣誉；当时175条资料中24项正式收录、151项待核查。2026-09-13已根据具名结果及完整标准收录宝鸡生产的第四代博越L，详见[实际应用记录](cars-and-motorcycles-evidence.md)。研究和收录数量不能用于推断全国企业守法比例。

## 可用于判断的证据

| 资料 | 怎样评估 | 不能直接推断的内容 |
| --- | --- | --- |
| 政府劳动守法评级 | 具名制造或服务法人、最终结果、覆盖期和复核日期；A级可支持收录 | 其他法人、未经对应的工厂和未来所有用工情况 |
| 政府综合劳动评价 | 核对正式结果及评价标准，确认覆盖劳动合同、工资与加班报酬、社保、工时、休息和劳动保护 | 税务A级、质量合格或仅证明没有欠薪，不是综合劳动结论 |
| 独立劳动审核 | 核对出具机构、原始报告或可查验的发证记录、适用中国劳动要求、权益覆盖范围、企业或工厂、时期及结论 | 企业网站“通过审核”的宣传、认证标志或孤立的证书图片，不等于审核已独立核实 |
| 企业披露、招聘和其他线索 | 记录已知事实，补充具体劳动制度及继续调查的方向 | 不因未查到处罚便自动认定合规，也不因没有政府评级就判为违法 |

政府综合劳动评价并非空泛荣誉的统称。例如[和谐劳动关系创建意见](https://www.mohrss.gov.cn/SYrlzyhshbzb/ztzl/xsdhxldgx/zcwj/202301/t20230103_492690.html?bsh_bid=5907708910)规定了权益保障、评审和动态管理要求；使用具体结果时，仍须核对该批次的标准、最终名单和适用企业。[劳动保障守法评价办法](https://www.szgm.gov.cn/szgm/132104/132207/132452/content/post_8722060.html)是另一类行政评价依据，不能与其他称号混为同一种等级。

[SA8000标准制定机构的说明](https://sa-intl.org/resources/sa8000-standard/)可作为独立劳动审核的一个框架示例。项目不要求企业必须取得SA8000，也不把私人标准的额外要求变成中国商品的统一准入条件。任何审核资料都需确认实际适用的中国劳动要求及具体工厂，不能凭名称自动承认合规。

## 数据怎样记录

沿用企业的`assessments`和商品的`productionLabor.assessmentSourceId`，保留原有政府A级资料。

- `government-labor-rating`：政府劳动守法评级，保留`grade`。
- `government-labor-review`：其他政府综合劳动评价。
- `independent-labor-audit`：已核对原始依据的独立劳动审核。

后两类记录出具机构`issuer`、适用范围`scope`、核验原始记录`verificationSourceId`、判断标准等资料`basisSourceIds`和劳动权益覆盖项`coverage`。结论`conclusion`区分`supported`（有依据支持）、`unresolved`（仍有待解决问题）、`adverse`（存在相反劳动事实）。只允许有依据支持、范围完整且在复核期限内的记录用于收录。这些字段记录研究者的证据判断，程序不能替代原始资料核查或法律判断。

`scopeType`区分整个用人单位与具体工厂。工厂限定的审核必须通过`facility`对应到商品的实际生产工厂，不能仅凭法人相同就套用。资料公开完整覆盖期时，保留`periodStart`、`periodEnd`；政府综合劳动评价或独立劳动审核未公开完整起止日，但具有可核验的正式结果时，可以填写与原始结果来源一致的`resultPublishedAt`，并在`period`中明确评价年份及“完整审查起止日未公开”。不得用公布日、评选日程或本站查阅日虚构实际审查区间；只有获奖口号或局部检查仍不满足综合劳动依据要求。所有类型均保留本站查阅、复核日期。若证书有有效截止日，另填`validUntil`；截止日当日仍有效，次日停止使用。证书有效期不冒充实际检查覆盖期，本站复核日期也不替代发证机构期限。

判断新旧记录时优先使用公开的覆盖期末日；没有完整覆盖期的综合结果使用其公布日。更新的适用不利结论仍会阻止引用旧记录。公布日用于记录排序，不表示该日曾现场检查，也不推定此前或此后所有生产活动均合规。

新的适用综合结果、相反事实、撤回或到期会阻止继续使用旧依据。局部检查中未涉及其他权益，不自动推翻已有综合评价；若查到适用的相反劳动事实，则须重新判断。未知资料、其他工厂的结果和未来日期均不冒充当前适用结论。

## 研究节奏

1. 先查现有企业和商品档案，优先补已有具体商品的关键缺口。
2. 同时查政府结果与可核验独立材料，不能只围绕A级名单搜索。品牌、生产、销售关系分别记录。
3. 单一候选的初次调查通常控制在两轮定向检索或约10分钟。仍无新线索时记录检索范围、结果、缺口和下次值得检查的条件，推进下一个需求。出现有用的原始报告或主体对应关系时，可以继续完成这条证据链。
4. 已因访问限制失败、规格不匹配或重复结果中止的路径，没有新证据就不重复。新报告、明确的新链接、主体纠正或到期复核可触发重新调查。
5. 分开记录新增具体资料、补齐销售或制造依据、正式收录和缺口。不能用待核查数量冒充已经找到守法商品，也不能把研究失败解释为企业违法。

本次回归验证覆盖三种证据入口、局部证据不足、同法人不同工厂、证书期限、后续相反事实、未来资料和分享筛选。现有政府评级、国内销售和境内生产判断继续保留。
