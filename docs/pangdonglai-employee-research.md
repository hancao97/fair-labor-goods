# 从员工反馈追到食品生产者

查阅日期：2026-09-13。

本批沿用“员工反馈 → 公司研究 → 对应商品”的顺序。企业页新增“有员工反馈”筛选，搜索也能匹配反馈中的岗位；企业下方的商品分别标明“已收录”或“待核查”。目前有3家企业、6条结构化员工经历，不能作为全国企业工作条件的抽样统计。

## 胖东来

优先核对公开员工采访，而不是把营销号的高薪、休假数字直接当作事实：

- [2026-09-02蓝鲸新闻采访的转述](https://news.china.com/socialgd/10000169/20260902/49716013.html)：受访员工认可薪酬、稳定性及福利，也强调相应的工作付出；岗位与签约法人未公开。供应商要求来自咨询人士的部分，不作为具名工厂已经通过审核的证据。
- [2024-11-26封面新闻采访的转载](https://finance.sina.cn/2024-11-26/detail-incxnmtq6881860.d.html?vt=4)：离职员工认可薪酬与年假，同时批评文化考核及家访。报道说明记者核实过身份，公开时使用化名；本站未独立核实其身份，也未把旧经历当作目前全部岗位情况。

随后从[官网中央厨房介绍](https://web.azpdl.cn/about?name=%E8%AE%B8%E6%98%8C%E4%B8%AD%E5%A4%AE%E5%8E%A8%E6%88%BF)及[河南日报现场报道](https://dzb.henandaily.cn/html5/2025-02/07/content_15_1719904.htm)对应到具体食品，新增四条研究记录：芋泥麻薯酥饼、红豆蛋黄酥饼、黄豆芽、绿豆芽。口味来源另见[时代财经报道](https://finance.ifeng.com/c/8cognaWR83C)。未核实的重量、包装、现价不填成确定规格；官网厂区介绍不冒充单品下单页。

四条记录的境内生产说明已补齐，当前单品购买资料及制造者劳动依据仍待核。未新增正式收录商品，也没有将胖东来商场销售的其他品牌或代工商品一起通过。

2023年食品招聘资料虽有工时、加班时薪和厂区地址，也出现健康及外貌等招聘限制，没有将其选取为全面合规依据。旧裁判讨论、未具原出处的高福利帖和AI生成文章不用于补足结论。没有查到资料不等于企业违法。

## 其他生产企业线索与停止条件

- 宝洁新增[2022年生产智造岗位分享](https://www.nowcoder.com/discuss/410359413058416640)，区别于之前的办公室经历。帖子带校招邀请，未具名具体工厂，也未给出实际周工时及加班费，标为招聘介绍性质的线索。未新增宝洁商品。
- 好来化工的新增结果仍以招聘页为主，混有重庆办事处与台湾旧经历；没有移用为中山工厂员工体验。
- 狮王青岛出现2026年牙刷设备维修招聘，属于岗位承诺；同页其他公司的“双休”没有归给狮王。
- 宝洁太仓车间技术员的历史点评索引可供后续定位，原页请求超时；未把汇总页其他岗位的下班时间归给技术员。

官网入口、中央厨房介绍、具名政府结果及两篇胖东来员工采访均取得普通HTTP正文。官网所链的三份飞书资料无法访问，停止请求；不绕过限制，也不把链接存在说成正文已核验。继续研究须有新的具体工厂反馈、适用劳动资料或现售商品来源，不重复同一搜索与失败路径。
