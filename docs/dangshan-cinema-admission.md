# 砀山影院收录复核

复核日期：2026-09-13。

本批将“砀山万达广场店 · 成人单场选座观影”转为正式收录，首次补上电影需求。共258条商品和服务资料，45项正式收录、213项待核查；196项细分需求中43项已有正式商品或服务、153项尚未正式覆盖。本批新增1条来源，总计806条；没有新增企业或员工反馈记录。

这是根据单店渠道、实际经营记录与主体对应作出的收录判断。此前因没有实时场次而保留销售待核，额外提高了[现有销售规则](admission-standard.md)的要求。现在支持具体国内观影服务及其渠道，同时明确未知的当天场次；没有把2月票房统计当作9月13日可下单的证明，也没有补造具体影片、票价或放映格式。

劳动依据只适用于该分店及所列年份。历史特殊工时批复已于2025-06-01届期，仍保留说明，不作为当前许可。资料复核期限是本站计划，不是政府保证的有效期。当地影院服务不代表影片摄制、其他万达分店或零食代工企业均在同一评价范围。
