# 发布机构核验与候选企业复核

查阅日期：2026-09-13。

本批修正政府资料只能来自`.gov.cn`域名的程序限制，新增华绿江苏生产企业档案，并补充高品乐和天宝食用油的定向检索结果。没有新增商品或改变正式收录名单：全站仍为239条商品与服务资料、34项正式收录、205项待核查；企业档案增至168份、来源增至676条。193项细分需求中31项已有正式商品，162项尚未正式覆盖。

## 来源身份与劳动结论分开核对

此前校验器直接拒绝非`.gov.cn`网址的政府劳动结果。公共机构可能使用其他域名，这个网址条件不是劳动合规要求。现在允许提供单独的发布机构核验记录：政府原始资料须能对应发布者及准确网址，数据中记录获核验的具体主机名、核验来源和查阅时间。相似域名、未核对子域、企业自行宣称的身份和晚于评价复核时间的核验不能通过。

真实例子是[湖南省政府公开的平台名录](https://www.hunan.gov.cn/zqt/zcsd/202604/33966527/files/7b6359cd3d05403a95464c665780688b.pdf)第1页第8行，明确列出江苏省中小企业公共服务平台、江苏省中小企业发展中心及`www.smejs.cn`。[江苏省工信厅的建设报道](https://gxt.jiangsu.gov.cn/art/2024/12/24/art_6301_11454743.html)和[平台页尾](https://www.smejs.cn/)补充了主管与运营关系。

本次只按政府名录核验`www.smejs.cn`，没有把全部子域或所有转载一并认可。机构身份核验不会将平台介绍、招聘、海关信用或一份未核对适用范围的材料变成综合劳动结论。具名结果、劳动权益范围、适用企业、日期及相反事实的判断继续保留；现有商品没有因这次代码修改而自动升级。

## 已有商品的缺口与停止条件

- **高品乐复印纸**：招聘平台有劳动诚信A级标签，但没有公开评价年度和原始决定。新找到的[政府信用红榜原页](https://www.xinhui.gov.cn/zwgk/ztzl/xyw/hb8/content/post_2851770.html)明确是海关高级认证。记录这一区别，等待具名劳动结果；不重复访问已受限的新会2025年名单附件。
- **天宝一级葵花籽油5L**：[2026-09-10采购公告转载](https://www.yfbzb.com/winbid/detail/20260910_630018405.html)公开部分列沙湾市悦购百货超市及同规格4桶记录。它比旧抽样多提供了具体近期流通线索，但原始公告、合同及面向个人的购买方式尚未取得，销售检查保持待核。没有访问平台隐藏字段，也没有将采购单价写成当前个人售价。
- **德美佳厨具、琦轩陶瓷**：前者的MELANSTAR线索仍限海外渠道；后者新增的生产项目规划不证明所选办公杯已经由其制造。本轮没有对应到可新增的国内商品，暂不重复通用品牌搜索。
- **晨光与盖瑞**：本次有限补查未取得K35生产法人的新劳动结果，也未解决盖瑞200g盒装涉及多个制造企业的既有问题；两款状态不变。

这些结论只描述本次资料取得范围。缺少证据、存在不同产品或遇到访问限制，都不能推断企业违法或全国企业守法比例。

## 验证

回归检查覆盖经政府资料核验的外部发布平台、相似域名和未核对子域、平台自证、企业宣传冒充劳动结果及未来核验日期。另运行全量数据校验、现有测试和生产构建；没有使用浏览器界面自动化。
