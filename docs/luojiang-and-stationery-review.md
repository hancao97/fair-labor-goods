# 洛江企业、童鞋与景区资料复核

整理日期：2026-09-13。本批新增3份具名企业档案、3条待核查商品与服务资料、12条来源。正式收录仍为34项，没有将企业有劳动依据写成其所有商品均已核实。全站242条资料中208条待核查；新增童鞋需求后，194项细分需求中31项有正式商品、163项尚未正式覆盖。

此前商品少，既有具体证据缺口，也有项目自身只接受A级、重复检索和额外条件的问题。现行规则已经接受政府综合劳动评价及可独立核验的劳动审核，见[方法修正](evidence-review-policy.md)。本批按企业出发补查，并分别记录制造、销售、开放状态的缺口，研究数量不用于推断中国企业守法比例。

## 其他定向检索与停止条件

- **文具制造主体**：昆山2022年名单中的马培德是贸易公司，既有研究已记录；不能挪给办公用品制造公司。新找到的2025年105822CH橡皮抽查线索仍需对应实际工厂的劳动结果。雄狮、昆山狮印与顺德工业的初查未形成可直接使用的完整结果；招聘页提及历史称号、个人劳动者表彰均未自动升级。
- **中天世纪深圳工厂**：[企业介绍](https://www.chungtin.com.cn/en/page-41034.html)中的2015、2016守法称号及[2018年协会转载名单](https://www.ba500.org/nd.jsp?_ngc=-1&fromColId=-1&id=670)可作为线索，尚缺原始具名劳动结果和实际代工商品。客户品牌关系不能替代商品标签。
- **宝山综合评价**：已读[2023年278家达标企业正式决定](https://xxgk.shbsq.gov.cn/article.html?infoid=14060f4d-8906-475a-b11e-d03a37ac339e)的公开索引，找到天晴纸业、美好家、爱优特等候选。尚未取得其所引宝府办〔2017〕35号的完整评价标准；爱优特产品页为系列资料，在线商城公开页未提供可对应的具体商品。未据称号或空商城新增正式商品。原网页普通下载返回403，停止该路径，不绕过限制。
- **金箩大米**：本轮仍回到既有福源爱展示页及其他规格的制造记录。页面已声明不直接销售，不能把购物车外观当作真实零售；无新同款渠道时停止重复检索。

两款永高人童鞋在取得制造原件和准确购买入口后继续；和诚在取得具名制造货号后继续；仙公山以晚于9月1日的恢复公告及适用票务信息为下一步依据。三家企业的劳动结果安排于2026-10-13前复查，复查日期不冒充政府评价有效期。
